This project is meant to demonstrate skills learned and used for data analysis including...
1.) Loading dataset into Python (Jupyter Labs) to perform EDA (exploratory data analysis) & data cleaning.
2.) Running SQL queries on PostgreSQL/SQL servers
3.) Building a PowerBI dashboard with toggles for insights for shareholders
4.) Development of a report explaining how decisions / insights were gathered
5.) Generation of a powerpoint via Google Gemini (time saver).
